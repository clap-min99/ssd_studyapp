## 이번 레슨의 목표

논리 요소의 조합·저장 경로를 설명하고 LUT 분해와 레지스터 사이의 타이밍 예산을 계산합니다.

## 앞에서 배운 내용

LUT는 함수를 표로, 플립플롭은 상태를 저장했습니다. FPGA는 이런 작은 블록과 연결 경로를 재설정해 큰 회로를 구성합니다.

## 설정 비트가 기능과 배선을 결정한다

FPGA(field programmable gate array)는 설정 가능한 논리 요소와 라우팅, 입출력 요소를 포함합니다. 교육용 논리 요소를 ‘4입력·1출력 LUT 한 개와 플립플롭 한 개, 출력 bypass MUX’로 가정합니다. LUT 결과를 바로 내면 조합 함수이고 플립플롭을 거치면 에지에서 저장된 함수입니다. 실제 제품은 LUT 크기·분할·캐리 체인·RAM·DSP·클록 자원이 다르므로 이 모델의 개수를 모든 장치에 적용하지 않습니다.

4입력 LUT는 입력 조합 16개의 출력 비트를 설정합니다. 입력이 네 개보다 많은 함수는 중간 함수를 만들어 여러 LUT로 나눌 수 있습니다. 예를 들어 6입력 AND는 t=A·B·C·D, Y=t·E·F로 두 4입력 LUT에 들어갑니다. 한 LUT의 출력은 다음 LUT 입력으로 배선을 통해 연결됩니다.

FSM에서는 LUT가 다음 상태 함수, 플립플롭이 현재 상태를 맡고 그 출력이 LUT 입력으로 돌아갑니다. 필요한 상태 비트 수만큼 저장 자원이 필요하지만, 다음 상태·출력이 복잡하면 추가 LUT가 필요합니다. 전용 캐리 체인은 덧셈기의 매 비트를 일반 LUT 여러 개로 분해하는 것보다 효율적으로 처리할 수 있습니다.

구현 흐름은 HDL 기능 확인 → 합성 → 배치·배선 → 타이밍 분석 → 설정 데이터 생성입니다. SRAM으로 설정을 저장하는 장치는 전원을 끄면 설정을 잃어 다시 로드해야 합니다. Flash나 다른 설정 방식도 있으므로 FPGA 전체를 같은 휘발성으로 일반화하지 않습니다. 여기서는 특정 보드·현재 제품 추천 대신 회로 구조를 학습합니다.

## 논리 함수의 입력 수와 저장 비트 수를 따로 세기

교육용 4입력·1출력 LUT는 최대 네 변수의 함수 한 개를 만들 수 있습니다. 6입력 AND가 한 LUT에 안 들어가는 이유는 식이 길어서가 아니라 독립 입력이 여섯 개이기 때문입니다. 중간 t=A·B·C·D를 만들면 다음 LUT는 t,E,F 세 변수를 읽으므로 각각의 입력 제한 안에 들어갑니다.

플립플롭 한 개는 상태 한 비트입니다. 4비트 상태가 필요하면 이 교육 모델에서는 적어도 플립플롭 네 개가 필요하지만 다음 상태 함수가 각 LUT에 다 들어갈지는 별도입니다. 출력 디코드나 복잡한 입력 함수에 추가 LUT가 필요할 수 있습니다. 실제 FPGA는 여러 출력 LUT·전용 캐리·메모리 자원 등으로 단순 모델과 다른 결과를 낼 수 있습니다.

타이밍은 두 레지스터 사이 경로로 풉니다. 송신 clock-to-Q,모든 조합·배선 지연,수신 setup을 합한 값이 주기 안에 들어야 합니다. 저장 비트 수를 줄여도 라우팅이나 논리 깊이가 늘면 느려질 수 있고,단순 LUT 개수만으로 주파수를 정할 수 없습니다.

## 따라 풀기

6입력 AND의 두 LUT 연결에서 A,B,C,D가 모두 1이면 t=1이고 E=1,F=0이면 Y=0입니다. 타이밍은 주기 4ns,t_pcq=0.20ns,t_setup=0.10ns,스큐=0이라고 가정합니다. 각 LUT와 그 뒤 배선의 합산 지연을 0.55ns로 가정하면 L단계에 0.20+0.55L+0.10≤4가 필요합니다. L≤6.727이므로 최대 6단계이며 7단계는 4.15ns로 실패합니다. 모델 밖의 별도 배선 지연을 또 더하거나 중복 계산하지 않습니다.

### 조건을 바꾸어 한 번 더 풀기

교육 모델에서 두 상태 비트 s1,s0와 입력 x의 함수로 각 다음 상태가 정해지는 FSM을 생각합니다. 각 함수는 변수 세 개이므로 다음 상태용 LUT 두 개와 플립플롭 두 개에 들어갈 수 있습니다. 별도 출력 y가 두 상태의 XOR라면 전용 출력 경로나 공유 자원이 없다는 가정에서 출력용 LUT 한 개가 더 필요할 수 있습니다.

이후 주기 4ns 예산에서 LUT·배선 단계가 한 개 더 생기면 0.55ns가 추가됩니다. 기존 6단계의 3.60ns는 통과하지만 7단계의 4.15ns는 실패합니다. 배치와 실제 라우팅은 이 단순 일정 지연 가정 밖입니다.

## 헷갈리기 쉬운 점

논리 요소 수만으로 속도를 예측하지 않습니다. 긴 라우팅과 팬아웃도 지연을 만듭니다. 합성 통과는 배치·배선 타이밍 통과와 다릅니다. 레지스터를 추가하는 파이프라인은 주기뿐 아니라 지연·제어 정렬 명세도 바꿉니다.

### 적용 문제: 직접 구성하고 이유 설명하기

교육용 4입력·1출력 LUT로 7입력 XOR를 만듭니다. 중간 함수를 정해 두 LUT로 나누고,입력 넷 모두 1·나머지 셋 0인 경우를 검산하세요. 여기에 출력 레지스터를 붙이면 기능의 관찰 시점은 어떻게 바뀌나요?

<details>
<summary>적용 문제 풀이와 검산</summary>
<p>t=A XOR B XOR C XOR D,Y=t XOR E XOR F XOR G로 나누면 각 LUT의 독립 입력은 네 개입니다. A부터 D까지 모두 1,E부터 G까지 0이면 t=0,Y=0으로 전체 1의 개수 네 개의 짝수 패리티와 맞습니다.</p>
<p>조합 출력은 현재 입력의 함수이고 출력 레지스터를 거치면 지정 에지에서 샘플한 결과가 갱신 후 보입니다. 저장을 추가하면 지연과 입력/제어 정렬의 계약도 바뀝니다.</p>
</details>
