## 이번 레슨의 목표

선택 심화입니다. 정상 경로와 스캔 경로를 구별하고 상태 주입·한 번 동작·관찰 순서를 설명합니다.

## 앞에서 배운 내용

시프트 레지스터는 적은 핀으로 여러 저장 비트를 옮길 수 있었습니다. 내부 플립플롭 상태에도 같은 접근을 적용합니다.

## 상태를 만드는 긴 입력 이력을 직렬 주입으로 대체한다

순차 회로는 현재 입력만으로 출력이 정해지지 않으므로 원하는 내부 상태에 도달하는 데 많은 클록이 필요할 수 있습니다. 스캔 체인(scan chain)은 시험 모드에서 플립플롭들을 직렬 연결해 원하는 상태를 넣고 기존 상태를 밖으로 읽는 구조입니다.

각 플립플롭 앞 MUX는 test=0이면 정상 다음 상태 D를, test=1이면 앞 스캔 단계의 출력을 고릅니다. 첫 단계만 scan_in을 받고 마지막 단계는 scan_out으로 나옵니다. 상태를 N비트 주입하려면 N번 이동하고, 정상 모드로 바꾸어 기능 클록을 준 뒤, 결과를 직렬로 관찰합니다.

대표 흐름은 ‘스캔으로 상태 주입 → 정상 모드에서 한 번 동작 → 다시 스캔으로 관찰’입니다. 스캔 핀을 통해 조합논리를 직접 바꾸는 것이 아니라 플립플롭의 저장값을 제어·관찰합니다. 실제 설계에서는 시험 모드·클록·reset·압축·전력·타이밍까지 고려하므로 여기의 한 체인 예제는 DFT 전체 과정이 아닙니다.

스캔 중에도 다음 상태 조합논리가 바뀔 수 있으며, 이동 자체가 저장 상태를 덮어씁니다. 따라서 정상 시스템이 계속 같은 상태로 실행되면서 내부 값을 몰래 읽는 디버거라고 가정하지 않습니다.

## 스캔 모드와 정상 모드가 선택하는 D 입력

스캔 플립플롭의 D 입력은 test=0이면 정상 조합논리의 다음 상태이고 test=1이면 이전 스캔 단계의 Q입니다. 두 입력을 MUX로 고르므로 플립플롭 자체는 같은 에지 저장 동작을 합니다. 모드를 바꾸는 것은 계산 공식을 바꾸는 것이 아니라 어느 데이터 경로를 저장할지 바꾸는 것입니다.

시험은 세 단계로 나눕니다. 먼저 목표 직전 상태를 직렬로 주입합니다. 이어 정상 모드에서 입력을 준비해 한 기능 전이를 실행합니다. 마지막으로 결과 상태를 직렬로 꺼내 기대값과 비교합니다. 주입 때 들어가는 비트와 관찰 때 나오는 비트의 순서는 체인 연결에 맞춰 정해야 합니다.

스캔은 내부 상태에 빠르게 접근하는 수단이지만 모든 정상 입력·모든 타이밍을 자동 검증하는 것은 아닙니다. 같은 상태라도 정상 경로의 어떤 입력을 시험할지, 기대 다음 상태가 무엇인지 별도로 정합니다. 스캔 경로 자체에 결함이 있을 수 있어 정상 기능 검사 전에 체인 이동도 확인합니다.

## 따라 풀기

8비트 카운터의 01111111→10000000 전이를 검사합니다. 단순 reset 후 세면 해당 상태에 도달할 때까지 127번 증가해야 합니다. 스캔으로 01111111을 8번에 주입하고 정상 모드에서 1클록 증가시킨 뒤 8번에 결과를 읽으면 총 17클록입니다. 직렬 순서는 레슨16처럼 MSB부터 주입하는 체인으로 약속합니다. reset·모드 전환의 별도 대기는 이 교육용 수에서 제외했습니다.

### 조건을 바꾸어 한 번 더 풀기

4비트 카운터의 0111→1000 전이를 검사한다고 합시다. test=1에서 0,1,1,1을 순서대로 주입하면 q는 0000,0001,0011,0111입니다. 정상 test=0,en=1로 한 에지를 주면 1000입니다. 다시 test=1로 0을 넣으며 읽으면 에지 직전 출력열은 1,0,0,0입니다.

주입 4회+기능 1회+관찰 4회=9회입니다. 관찰 후 내부 q는 더 이상 1000이 아닐 수 있으므로 계속 정상 실행하려면 상태를 다시 준비해야 합니다. 값을 읽는 행위 자체가 체인을 이동시킨다는 점이 일반 메모리 읽기와 다릅니다.

## 헷갈리기 쉬운 점

실제 결함을 잡으려면 출력 비트가 무엇이어야 하는지 독립 기대값을 가져야 합니다. 스캔 경로만 통과했다고 정상 조합 경로와 모든 타이밍이 검증되는 것은 아닙니다.

## 직접 확인하기

1. N=12에서 주입·정상 1클록·관찰의 합은?
2. test=0이면 플립플롭 입력은?
3. 스캔을 읽는 동안 원래 상태가 유지되나요?

### 적용 문제: 직접 구성하고 이유 설명하기

스캔으로 카운터 상태 1110을 넣고 정상 증가 두 번을 시험하려 합니다. 기대 상태와 관찰 출력열을 적고, 기능 에지 수가 늘면 총 클록 수를 어떻게 셀지 설명하세요.

<details>
<summary>적용 문제 풀이와 검산</summary>
<p>1110에서 정상 증가 한 번은 1111,두 번째는 0000입니다. 최종 상태를 MSB부터 네 번 관찰하면 0,0,0,0입니다.</p>
<p>주입 4+정상 2+관찰 4=10클록입니다. 이 수에는 모드 전환이나 reset의 별도 대기를 포함하지 않았습니다. 목표 시험이 중간 1111도 관찰해야 한다면 시험 절차가 달라집니다.</p>
</details>
