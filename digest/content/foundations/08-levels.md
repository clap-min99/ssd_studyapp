## 이번 레슨의 목표

입력·출력 논리 전압을 구별하고 잡음 여유를 계산하며, 두 회로가 같은 0과 1을 사용해도 연결이 보장되지 않는 이유를 설명할 수 있으면 됩니다.

## 앞에서 배운 내용

논리 게이트의 진리표는 입력이 유효한 0과 1이라는 조건에서 성립합니다. 레슨 2에서 남겨둔 전압 범위의 약속을 구체화합니다.

## 보내는 쪽의 출력 보장과 받는 쪽의 입력 요구

기준 전압 GND를 0V, 전원 전압을 V_DD라고 합시다. 신호를 보내는 회로는 드라이버(driver), 받는 회로는 리시버(receiver)입니다. 논리값을 구별하는 네 경계는 다음과 같습니다.

| 기호 | 이 레슨에서 사용하는 의미 |
| --- | --- |
| V_OL | 드라이버가 LOW일 때 보장하는 출력 전압의 상한 |
| V_OH | 드라이버가 HIGH일 때 보장하는 출력 전압의 하한 |
| V_IL | 리시버가 LOW라고 보장하는 입력 전압의 상한 |
| V_IH | 리시버가 HIGH라고 보장하는 입력 전압의 하한 |

입력이 V_IL 이하면 0, V_IH 이상이면 1로 읽습니다. **그 사이의 전압에서는 논리 동작이 보장되지 않습니다.** 제3의 정상 논리값이라는 뜻은 아닙니다. 실제 데이터시트는 부하·온도·전원 등의 조건을 붙이므로 경계값만 떼어 적용하지 않습니다.

## 따라 풀기

위 조건에서 LOW 잡음 여유는 `NM_L = V_IL−V_OL = 0.8−0.3 = 0.5V`, HIGH 잡음 여유는 `NM_H = V_OH−V_IH = 2.9−2.2 = 0.7V`입니다.

드라이버가 최악의 HIGH인 2.9V를 냈고 전송 중 전압이 0.4V 내려가면 2.5V입니다. 여전히 2.2V 이상이므로 HIGH로 보장됩니다. 0.8V 내려가면 2.1V라서 보장이 사라집니다. 이때 **반드시 0이 된다**는 뜻이 아니라, 1이라는 보장을 할 수 없다는 뜻입니다.

연결할 두 부품이 다르면 식의 출력 경계는 드라이버 것, 입력 경계는 리시버 것을 씁니다. 두 잡음 여유가 음수가 아니어야 논리적인 연결 조건을 만족하며, 실제 설계에서는 충분한 양의 여유를 확보합니다.

## 천천히 전압을 바꾸면 보이는 것

인버터 입력을 천천히 올리며 출력을 그린 것이 **DC 전달 특성(DC transfer characteristic)** 입니다. 이상적인 인버터는 한 점에서 출력이 갑자기 떨어지지만, 실제 회로는 중간 전압을 지나 부드럽게 변합니다. 전환부에서 입력의 작은 변화가 출력의 큰 변화로 증폭될 수 있습니다.

책에서는 전달 곡선의 기울기가 −1인 두 지점인 단위 이득점(unity gain point)을 기준으로 입력 논리 경계를 정하는 방법을 설명합니다. 모든 실제 부품의 경계가 무조건 전원 전압의 절반이라는 뜻은 아닙니다. DC는 정적·천천히 변하는 상황이고, 빠른 변화에 따른 지연은 2장에서 다룹니다.

## 정적 규율을 지키면 회로를 조합할 수 있다

**정적 규율(static discipline)** 은 유효한 논리 입력에 대해 회로 요소가 유효한 논리 출력을 만들도록 하는 약속입니다. 같은 논리 계열(logic family)은 서로 연결할 수 있도록 전압 규격을 맞춥니다. 이 약속은 시간이 전혀 걸리지 않는다는 뜻은 아닙니다.

## 헷갈리기 쉬운 점

논리 경계의 호환성과 입력의 전압 허용 한계는 별개입니다. 예를 들어 5V HIGH를 3.3V 부품이 논리 1로 알아볼 수 있어도, 그 입력이 5V를 견딘다는 보장이 없으면 손상될 수 있습니다. **논리 경계·허용 전압·부하 조건을 함께 확인**해야 합니다. 이 레슨의 숫자로 실제 부품을 연결하면 안 됩니다.

## 직접 확인하기

1. 드라이버 V_OL=0.2V, V_OH=2.8V, 리시버 V_IL=0.7V, V_IH=2.0V라면 두 잡음 여유는 얼마인가요?
2. 이 리시버에 1.3V가 들어오면 0이라고 보장할 수 있나요?
3. 정적 규율을 만족하면 회로 지연도 자동으로 0이 되나요?
