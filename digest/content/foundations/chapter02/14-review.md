## 이번 레슨의 목표

동작 명세에서 식과 구현을 만들고, 기능과 시간·미지값 조건을 분리해 검사할 수 있으면 됩니다. 이 장의 각 단계를 설명하며 직접 문제를 풀어보세요.

## 앞에서 배운 내용

진리표를 SOP·POS로 쓰고, 불 대수·카르노 맵으로 줄여 게이트·MUX·디코더로 구현했습니다. 마지막으로 같은 함수라도 지연과 글리치가 다를 수 있다는 것을 배웠습니다.

## 설계의 순서를 끝까지 연결한다

| 단계 | 남겨야 할 근거 |
| --- | --- |
| 명세 | 입력·출력 의미, 모든 입력에서의 요구, don't care 근거 |
| 진리표·표준형 | 변수 순서, 빠짐없는 행, SOP 또는 POS |
| 단순화 | 사용한 법칙·그룹, 요구된 모든 행에서의 동치 |
| 구현 | 중간 신호·게이트 연결, 구동 규칙, 구현 대안 |
| 시간 검토 | 경로·입력 도착 시각·안정 시각·글리치 사용 조건 |

합성 도구를 사용해도 명세를 정확하게 정하는 일은 설계자의 몫입니다. 다음 장 이후에 더 큰 시스템을 배울 때도 기능과 시간의 약속을 함께 확인합니다.

## 따라 풀기

A가 허용 신호, B와 C가 요청 신호이고, 허용 중에 요청 하나 이상이 있으면 F=1인 조합 회로를 설계합시다.

1. 문장을 식으로 옮기면 `F=A·(B+C)`입니다. 과거 요청을 기억하지 않는다는 조건입니다.
2. 변수 순서를 ABC로 정하면 출력 1은 101·110·111이므로 `F=Σm(5,6,7)`입니다.
3. 101·111을 묶으면 AC, 110·111을 묶으면 AB여서 `F=AB+AC`입니다. 111의 중복은 허용됩니다.
4. OR 뒤 AND로 `A·(B+C)`를 구현하거나, AND 두 개 뒤 OR로 AB+AC를 구현할 수 있습니다. 사용 가능한 게이트와 지연을 비교합니다.
5. OR t_pd=3ns·AND t_pd=2ns이고 모든 입력 도착이 0이면 첫 구현에서 B/C 경로는 5ns, A 경로는 2ns입니다. 이 모델의 최종 안정 시각 상한은 5ns입니다.

이 결과는 기능 예제이며 실제 장치의 안전 기능·인터럽트 회로 설계를 대신하지 않습니다. ‘요청이 과거에 한 번이라도 있었으면 기억한다’로 요구가 바뀌면 이번 조합식만으로는 충분하지 않습니다.

## 헷갈리기 쉬운 점

don't care를 넣어 표를 바꾸고도 예전 표와 완전히 같은 함수라고 말하면 안 됩니다. Z와 X를 정상적인 0·1과 동일시하지 않습니다. 최소 SOP가 가장 빠른 물리 회로라고 단정하지 않고, 논리적으로 제거 가능한 항도 글리치를 막는 데 필요할 수 있음을 기억합니다.

## 직접 확인하기

1. `F=Σm(5,6,7)`에서 출력 0인 행의 번호와 POS 표준형을 써보세요.
2. `AB+¬A·B`를 줄이고, `¬(A+B)`를 드모르간 법칙으로 바꿔보세요.
3. 3변수 맵에서 `Σm(1,3,5,7)`의 최소식은 무엇인가요? 출력 0으로 지정된 칸을 함께 묶을 수 있나요?
4. 두 요청 10·01이 모두 가능한 버스에서 각 출력을 상시 연결하면 왜 안 되나요? 비활성 3상태 버퍼의 출력은 무엇인가요?
5. F=A·(B+C)를 4:1 MUX로 만드세요. 선택선은 AB, 데이터 입력은 C·¬C·0·1 중에서 고릅니다.
6. 같은 F를 3:8 디코더와 OR로 만들면 어느 출력을 사용하나요?
7. NOT t_pd=1ns, AND=2ns, OR=3ns이고 가장 긴 경로가 NOT→AND→OR, 가장 짧은 경로가 OR라면 t_pd는 얼마인가요? t_cd도 이 정보만으로 알 수 있나요?
8. `AB+¬A·C`에서 B=C=1·A만 변할 때 글리치 방지에 도움이 되는 항은 무엇이며, 여러 입력의 모든 전환까지 보장하나요?

<p>4. 두 드라이버가 서로 다른 값을 낼 때 <strong>충돌</strong>합니다. 비활성 3상태 버퍼는 <strong>Z</strong>입니다. Z는 0이 아닙니다.</p>
