## 이번 레슨의 목표

논리식에서 중간 신호와 연결을 정하고, 여러 출력이 있는 우선순위 회로를 설계할 수 있으면 됩니다.

## 앞에서 배운 내용

진리표를 SOP로 옮기고 불 대수로 줄였습니다. 이제 같은 함수를 게이트 회로도(schematic)로 표현합니다. 회로를 그린 뒤에는 다시 식과 진리표로 돌아와 동작을 검사합니다.

## AND 항들을 만들고 OR로 합친다

SOP `Y=¬A·B+A·C`라면 먼저 A를 반전하고, 두 곱항을 AND로 만든 뒤 OR로 묶습니다. `n0=¬A·B`, `n1=A·C`, `Y=n0+n1`처럼 이름을 붙이면 식과 회로의 대응이 분명해집니다. NOT으로 보수를 만들고 AND 배열과 OR 배열을 놓는 규칙적인 형태는 PLA(programmable logic array)의 기본 구조와 연결되며 자세한 구현은 5장에서 다룹니다.

도면은 입력 왼쪽·출력 오른쪽으로 정리합니다. T자 접점은 연결되고, 교차점에 점이 있으면 연결, 점 없이 지나가면 연결되지 않습니다. 같은 입력을 두 게이트로 나누는 분기와 두 출력을 묶는 것은 서로 다릅니다.

## 여러 출력은 각각의 함수를 만든다

세 요청 R2·R1·R0 중 가장 높은 번호 하나만 승인하는 회로를 설계해봅시다. 요청이 없으면 모든 승인 출력을 0으로 둡니다. 출력 G2·G1·G0의 우선순위는 2>1>0입니다.

| R2 R1 R0 | G2 G1 G0 |
| --- | --- |
| 000 | 000 |
| 001 | 001 |
| 01– | 010 |
| 1–– | 100 |

이 표에서 **–는 0·1 어느 쪽이어도 해당 행의 결과가 같음**을 나타냅니다. 01–는 010과 011을 합친 두 행입니다. 1––는 네 행을 뜻하므로 전체 1+1+2+4=8조합을 빠짐없이 표현합니다. 아직 정하지 않은 값이 아닙니다.

## 따라 풀기

출력별 조건을 문장에서 식으로 옮깁니다.

1. 가장 높은 요청은 그대로 승인하므로 `G2=R2`입니다.
2. 1번은 2번이 없고 자신이 요청했을 때이므로 `G1=¬R2·R1`입니다.
3. 0번은 위의 두 요청이 모두 없을 때이므로 `G0=¬R2·¬R1·R0`입니다.

입력 011을 넣으면 G2=0, G1=1, G0=0입니다. 0번도 요청했지만 1번이 우선합니다. 출력 여러 개의 진리표를 만들고 공통 부정 입력을 공유하면 회로 전체를 규칙적으로 그릴 수 있습니다. 출력은 **최대 한 비트만 1(one-hot-or-zero)** 이며 아무 요청도 없으면 모두 0입니다.

## 헷갈리기 쉬운 점

각 요청을 그대로 각 승인으로 복사하면 여러 요청이 동시에 들어왔을 때 여러 승인이 켜집니다. 그것은 우선순위 회로가 아닙니다. 또한 표의 –를 실제 전선에 떠다니는 값으로 출력하는 것이 아닙니다. 동작을 줄여 적은 **명세의 약어**입니다.

## 직접 확인하기

1. 입력 101에서 G2·G1·G0는 무엇인가요?
2. `G0=¬R1·R0`로 잘못 만들면 어떤 입력에서 우선순위를 어기나요?
3. 도면에서 점 없이 교차하는 두 선은 연결되나요? 출력 노드 Y를 두 일반 게이트가 동시에 구동해도 되나요?
