## 이번 레슨의 목표

조합논리의 기능 명세와 시간 명세를 구별하고, 작은 회로를 연결할 때 지킬 규칙을 검사할 수 있으면 됩니다.

## 앞에서 배운 내용

1장에서 게이트 하나의 진리표와 전압 조건을 배웠습니다. 이제 여러 게이트를 묶어 원하는 함수를 만듭니다. **현재 입력만으로 안정된 출력이 정해지는 회로**가 조합논리 회로(combinational circuit)입니다. 과거 입력을 기억하는 순차논리 회로는 3장에서 다룹니다.

## 회로의 약속에는 답과 도착 시간이 모두 있다

회로를 블랙박스로 보면 입력, 출력, 기능 명세(functional specification), 시간 명세(timing specification)가 있습니다. 기능은 ‘어떤 답을 내는가’, 시간은 ‘입력 변화 후 언제부터 변할 수 있고 언제까지 안정되는가’입니다. 조합논리라는 말이 지연 0이라는 뜻은 아닙니다.

안쪽에는 게이트 같은 요소(element)와 신호를 전달하는 노드(node)가 있습니다. 외부에서 들어오는 입력 노드, 밖으로 나가는 출력 노드, 요소 사이의 내부 노드를 구별합니다. 하나의 출력 신호를 여러 입력으로 나눠 보낼 수 있지만, 일반 게이트 출력 여러 개를 한 노드에 묶으면 충돌할 수 있습니다.

## 조합 회로를 안전하게 구성하는 규칙

책의 조합 구성 규칙은 다음과 같습니다.

1. 각 요소 자체가 조합 회로입니다.
2. 각 노드는 외부 입력이거나, 정확히 하나의 요소 출력에 연결됩니다.
3. 한 노드를 다시 방문하는 순환 경로가 없습니다.

이 조건을 지키면 작은 조합 회로에서 큰 조합 회로를 구성할 수 있습니다. **충분조건**이지 모든 가능한 조합 회로를 판별하는 필요충분조건은 아닙니다. 예외적인 구조를 분류하려고 애쓰기보다 이 장에서는 위 규칙을 지켜 설계합니다. 레슨 6에서 다룰 tri-state 버스는 별도의 구동 규칙이 필요한 예외입니다.

여러 비트를 묶은 신호는 버스(bus)입니다. `A[3:0]`은 비트 3부터 0까지 네 신호의 묶음이며, 도면의 선에 사선과 숫자 4를 붙여 표시할 수 있습니다. 하나의 굵은 선이 하나의 논리값이라는 뜻은 아닙니다.

## 따라 풀기

`n = A·B`, `Y = n+C`인 회로를 봅시다. AND와 OR는 조합 요소이고, n은 AND만, Y는 OR만 구동하며, 출력에서 입력으로 돌아가는 경로가 없습니다. 따라서 구성 규칙을 만족합니다. A=1, B=0, C=1이면 n=0, Y=1입니다.

반대로 Y를 앞 게이트의 입력으로 되돌리면 순환이 생깁니다. 두 인버터의 출력을 그냥 묶어 Y로 만드는 것도 단일 구동 규칙을 어깁니다. 인버터 둘을 **직렬로 연결**하는 것과는 다릅니다.

## 헷갈리기 쉬운 점

‘입력이 같으면 출력도 같다’는 것은 안정된 상태의 기능 설명입니다. 입력이 막 변한 순간의 출력까지 즉시 맞는다는 보장은 아닙니다. 또한 여러 출력이 있어도 각각 현재 입력의 함수라면 조합 회로입니다. 전가산기의 합 S와 캐리 C_out도 이런 예이며 자세한 산술 구현은 5장에서 배웁니다.

## 직접 확인하기

1. 두 인버터를 직렬로 연결한 회로는 조합 구성 규칙을 만족하나요?
2. 현재 경고 입력이 0이어도 과거 경고를 기억해 출력을 유지한다면 조합논리만으로 설명할 수 있나요?
3. ‘Y=A+B’와 ‘입력 변화 후 4ns 이내 안정’은 각각 어떤 명세인가요?
