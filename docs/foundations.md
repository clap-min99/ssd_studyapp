# 컴퓨터 구조 기초: 마지막 장까지 유지할 작성 규칙

## 목적과 기준 자료

Harris & Harris, 《Digital Design and Computer Architecture, RISC-V Edition》의 흐름을 따라
한국어 설명·직접 만든 도식·풀이 예제·확인 문제로 공부하는 트랙입니다.
현재 완성 범위는 **1장 From Zero to One(디지털 설계의 출발점)**과
**2장 Combinational Logic Design(조합논리 설계)**,
**3장 Sequential Logic Design(순차논리 설계)**과
**4장 Hardware Description Languages(하드웨어 기술 언어)**,
**5장 Digital Building Blocks(디지털 구성 요소)**과
**6장 Architecture(RISC-V 아키텍처)**입니다.
기준 자료는 사용자가 제공한 733페이지 PDF이며, 원본이나 추출 전문을 저장소·배포 이미지에 포함하지 않습니다.
원문 문장·그림·연습문제를 복사하지 않고, 해당 범위를 읽고 설명·예제·문제를 새로 구성합니다.
아래 규칙은 이후 2장부터 마지막 장까지 동일하게 적용합니다.

9장은 목차에서 온라인 보충 장으로 안내하므로 제작 시 실제 본문 포함 여부와 자료 범위를 확인합니다.
부록은 필요한 레슨의 보충으로 연결합니다. 세부 레슨은 반드시 해당 장을 읽은 뒤 정합니다.

## 장 제작 순서

1. 본문·그림·수식을 읽고 절별 필수 개념·선수 지식·선택 심화를 목록으로 만듭니다.
2. 책의 절 순서와 개념 의존성을 유지하고 한 레슨에 하나의 중심 질문을 둡니다.
   긴 절은 나누되 출처 범위를 연결합니다. 분량을 줄이기 위해 필수 개념을 생략하지 않습니다.
3. 새 예제를 입력부터 중간 단계·결과까지 풀고 원문의 개념과 대조합니다.
   본문에 없는 응용은 보충이라고 표시하고, 미래 개념을 이미 아는 것으로 설명하지 않습니다.
4. 추출 텍스트만 믿지 않고 PDF 화면에서 수식의 부호·지수·변수·단위와 회로 연결을 확인합니다.
5. 마지막 레슨은 핵심 문제와 선택 심화를 구분하고, 막혔을 때 돌아갈 레슨을 알려줍니다.
6. 아래 검증 기준을 확인한 뒤 장을 완성으로 표시합니다.

아래 제목 순서를 고정하며, 개념별 설명 소제목은 사이에 추가할 수 있습니다.

점수·진도·정답 입력은 현재 범위에 없으며 스스로 풀어보는 문제입니다.

## 용어·기호·구현 원칙

- 한국어 용어를 먼저 쓰고 첫 등장에 영어를 병기합니다. 이후 같은 용어를 사용합니다.
- 비트 폭과 해석을 명시합니다. 번호는 오른쪽 LSB=0부터, 별도 표시가 없는 부호 있는 정수는 2의 보수입니다.
  이진수는 `1010₂`, 십진수는 필요할 때 `10₁₀`, 16진수는 `0xA`입니다. 주소·값·비트 패턴을 구분합니다.
- NOT `¬A`, AND `A·B` 또는 `AB`, OR `A+B`, XOR `A⊕B`를 사용합니다.
  부정 범위는 괄호로 표시하고 OR의 `+`와 산술 덧셈을 구분합니다. 책의 NOT 가로선과 표기 차이를 안내합니다.
- 전압은 `V_DD`, `V_IL`, `V_IH`, `V_OL`, `V_OH`로 씁니다. 식마다 변수·단위·조건을 설명합니다.
  동적 전력의 α는 **기준 주기당 0→1 충전 횟수의 평균**으로 통일합니다.
- 명세의 don't care는 `–`, 시뮬레이션의 미지값은 `X`, 고임피던스는 `Z`로 구분합니다.
  책의 don't care X 표기와 차이를 설명합니다. 지연은 `t_pd`·`t_cd`로 통일하고 ns·ps 단위를 명시합니다.
  진리표 행 번호는 명시한 변수 순서의 이진수이며 K-map 양축은 그레이 코드 순서입니다.
- 안정 상태/전환 중 동작, 이상적 모델/실제 부품, 회로 결과/언어 규칙을 구별합니다.
  교육용 전압·소자 값은 가정이라고 표시합니다. 실제 하드웨어 연결 지침으로 사용하지 않습니다.
- 이후 HDL 주 예제는 SystemVerilog, 기본 ISA는 책의 RV32I로 통일합니다.
  VHDL·다른 ISA 비교는 별도 표시하고, HDL의 병렬 회로를 프로그램 실행 순서와 혼동하지 않게 설명합니다.

## 그림·접근성·마크다운

- 기존 `.lesson-content`와 인라인 SVG를 재사용합니다. 렌더러·이미지 호스팅을 추가하지 않습니다.
- SVG에 `viewBox`, `role="img"`, 고유한 `title`·`desc`, `aria-labelledby`를 둡니다.
  색만으로 의미를 표현하지 않고 이름·상태·연결을 텍스트로도 설명합니다.
- 입력은 왼쪽, 출력은 오른쪽, 전원은 위, GND는 아래를 기본으로 합니다.
  정식 기호를 생략한 기능도·개념도는 캡션에 표시하고 그림과 진리표를 대조합니다.
- 앱 그림 번호는 장-레슨 번호, 여러 그림이면 a/b를 붙입니다. 책의 그림 번호와 구분합니다.
  기존 CSS 변수와 모바일에서 읽을 수 있는 글자·선 간격을 사용합니다. 넓은 표는 나눕니다.
- SVG 블록 안에는 빈 줄을 넣지 않습니다. raw HTML 해설에는 Markdown 강조를 섞지 않습니다.
  범위의 `~`는 `\~`로 이스케이프하고 `)**조사` 형태의 강조 깨짐도 검사합니다.
- 본문은 검토한 저장소 파일만 사용합니다. PDF 추출 전문이나 미검토 HTML을 자동으로 저장하지 않습니다.

### 책의 단순화와 구별한 보충

- 재귀는 M 확장 없이 핵심 흐름을 연습하도록 자체 재귀 합으로 구성했습니다. 책의 factorial은 동일한 저장 원리에 곱셈을 추가한 예로 연결합니다.
- 추가 스택 인자·프레임 포인터와 지역 배열은 레슨15 보충에서 설명합니다. 핵심 실행 예제는 8개 이하의 작은 정수 인자를 가정합니다.
- [공식 psABI](https://riscv-non-isa.github.io/riscv-elf-psabi-doc/)와 대조하여 ra를 caller-saved로 구분하고, 자신이 다음 호출 뒤 복귀할 주소를 미리 보존하도록 설명합니다. 책의 보존 표와 다르다는 점을 명시합니다.
- [RV32I 명세](https://docs.riscv.org/reference/isa/unpriv/rv32.html)로 JALR 목표 비트0 처리와 정렬을 보충했습니다. [M 확장](https://docs.riscv.org/reference/isa/unpriv/m-st-ext.html)의 나눗셈 경계 동작도 기본 RV32I와 분리했습니다.
- [Machine-Level ISA](https://docs.riscv.org/reference/isa/priv/machine.html)의 vectored 인터럽트는 BASE+4×cause를 사용하며 동기 예외는 BASE로 갑니다. 현대 CSR 분류 Zicsr·MRET과 기본 정수 연산을 구별합니다.
- 원문의 선택 심화는 요약 수준으로도 해당 개념을 빠뜨리지 않되, 특권 처리기 전체 구현·전체 x86 명령어 표·현대 ISA 확장의 전체 목록은 포함하지 않습니다.
